# 1800 mm 小黑柱原始点与360格对照

本测试用于判断：雷达是否收到目标回波、整数角度合并损失多少点、使用真实小数角度采样后候选是否改善。台架测试不写地图、不运行多圈保持，不把历史命中当成本圈命中。当前验收目标已按用户要求调整为1800mm；代码通过不代表该距离已经实测通过。文档和构建目录沿用原有2m命名以保留链接。

## 启用

`Test/Inc/lidar_pillar_test.h` 中 `LIDAR_PILLAR_TEST_ENABLE` 默认0，保留当前整车初始化及主循环。改为1后重新编译、烧录即可切换独立入口；也可编译时增加 `-DLIDAR_PILLAR_TEST_ENABLE=1`，不用修改默认值。

独立模式初始化调试串口USART6、雷达UART4、正余弦表、DWT计时器；不执行 `system_init()`，不启动整车定时器、电机初始化、里程计或地图任务。外设生成初始化仍由原有main执行，测试入口不发送任何电机指令。

当前1800mm独立固件另存为 `build/LidarPillar2mCheck/gongxun_1_1800mm.elf`；2026-10-22本次调整后242项主机检查与独立ARM编译通过。上电应看到 `PILLAR CONFIG ... target=1800`，再开始按键采集；未自动烧录。

参数在同一头文件：中心角默认0°，角区±8°；目标表面1800mm，沿目标方向前后容差150mm、横向容差100mm。中心角变更会同时改变原始采集角区与测试选区方向。两路使用雷达局部XY，**均不使用整车遮挡屏蔽**，这是固定台架对照，不等于正式实车过滤规则。实物应按1800mm摆放，1650~1950mm只是统计容差，不是将其它距离当作1800mm验收。

测距从雷达扫描中心量到柱子朝向雷达的表面。使用原样直径50mm、高100mm黑柱，固定雷达与柱子位置，并确认实际扫描面能打到柱身。卷尺、人和其它物体应离开目标扫描区域。

## 操作

1. 上电等待 `LIDAR PILLAR NATIVE / 360 TEST` 和第1轮背景提示。
2. 移走柱子，短按并松开KEY1，采集100个有效新扫描。
3. 等待第1轮有柱提示，在规定位置放入黑柱，手离开后短按KEY1，再采100圈。
4. 按提示完成第2、3轮背景/有柱对照；不要在采集过程中移动雷达。
5. 输出 `DONE` 后本轮实验结束，重新采集请复位。测试不会自动判断或改变姿态。

每组开始会丢弃附近两次新扫描；采集时的额外按键不会提前启动下一组。KEY1由主循环消抖，不依赖整车按键任务。

## 原始采样与聚类

在整数角度合并和零距离过滤前，旁路按接收顺序保存角度、距离、强度。角度用1/64°单位的16位整数保存，同一整数角度内的多个采样分别保留；不插值补采样。协议包内计算的小数角度被量化到1/64°，并不宣称提高雷达本身角分辨率。

每点6字节，角区每圈最多64点。双缓冲与原有扫描使用同一发布编号；零距离也保留。坏包会丢弃工作半圈，换角区后等待下一完整扫描分段；容量超出时记录overflow，不能静默截断后按完整结果统计。发布仍沿用原有起始包分段条件，不能证明完全没有静默丢失的协议包。

原始点通过已有正余弦表的相邻表值插值生成XY，一个真实采样只产生一个XY；按顺序、实际角度差与100mm空间点距分组，跨0°的邻点可成为同一组。角度连接上限为3°，对应现有允许缺2个整数角格的初始对照值。候选筛选调用正式 `obstacle_cluster_is_pillar()`，继续使用当前近3点/中2点/远1点及100mm跨度上限。

360格对照使用同圈原始 `lidar_scan_t` 的最近距离，按同一角区生成局部点云，再调用实际 `obstacle_cluster_update()` 与 `obstacle_cluster_is_pillar()`。为节约内存，这条测试路径复用已有全局cloud/obstacle_result，因此不得与正式建图同时调用。

两路候选都必须整体位于测试选区。选区只是已知目标位置的测量工具，不能将台架选区复制成正式全方向避障的裁剪规则。

## 日志含义

| 日志 | 含义 |
| --- | --- |
| `PILLAR FRAME` | 首3圈及每20圈的摘要；sector含零距离，target_raw和integer是目标区有效点数；native/legacy为候选命中标志/候选点数；d为目标原始点距离范围 |
| `PILLAR SAMPLE` | 每组首次目标原始命中的一个真实快照，含角度、距离、强度、局部XY；最多打印16个目标点，超过时明确报告；不增加统计命中 |
| `PILLAR RATE RAW` | 目标区至少收到一个有效原始点的圈数 |
| `PILLAR RATE INTEGER` | 目标区至少存在一个有效整数角格点的圈数 |
| `PILLAR RATE NATIVE` | 原始点局部聚类通过小柱筛选的圈数 |
| `PILLAR RATE LEGACY` | 360格聚类通过小柱筛选的圈数 |
| `PILLAR HIST` | 目标原始点数为0/1/2/3及以上的圈数分布 |
| `max_miss` | 同一连续有效扫描序列中的最长连续漏检圈数；接收中断或未观察扫描会断开序列 |
| `first_hit_ms` | 相对本组第一个有效扫描结束时间的首次命中时间，-1表示没有命中；它不是多圈确认耗时 |
| `PILLAR COST` | 原始转换/聚类和360格对照合计耗时的均值/最大值，单位us；DWT计时不含随后打印，可能包含中断时间 |
| `excluded` | 溢出、扫描配对失败等无法完整比较的发布扫描，不计入100圈分母 |
| `gaps` | 首末有效测量之间没有被统计的已发布扫描数；不人为补成命中或漏检 |
| `breaks` | 采集期间观察到的接收丢圈计数变化次数 |
| `xor_err/drop/log_drop` | 本组校验错误、丢弃扫描、日志未成功入队字节的增量 |

`BACKGROUND`阶段的候选命中是该选区里的误报候选；`PRESENT`阶段才用于比较黑柱检出。单点只能表示小障碍候选，不能证明颜色或圆柱形状。RAW命中而NATIVE无命中时检查分组和筛选；RAW本来没命中时，聚类无法补出真实测量。

原始角区缓冲约808字节，局部XY/有效标志共576字节，复用现有360格点云；其余仅为统计状态、配置和少量栈变量，不保存100圈整份点云。原始旁路默认关闭；日志限频，解析路径不打印。是否满足板上算力预算，以真实 `PILLAR COST`、丢圈和控制任务验证为准。
