# 定位模块与雷达建图接入

本次预留真实地图位姿接口，不启用自动驾驶。主循环仍运行原来的静止雷达地图测试。

## 定位端

在主循环收到一份新的定位结果后发布：

```c
map_pose_update(x_mm, y_mm, my_yaw, measurement_tick,
                localization_valid && yaw_valid);
```

- X/Y：车体原点的实际地图位置，单位mm，地图原点在场地下方左侧，与`map_track.c`一致。这里不是雷达原点，雷达安装偏移仍由`tf_base`负责。
- yaw：现有HWT101的`my_yaw`，单位度，允许多圈累计；不新增另一份角度解算。
- measurement_tick：本次测量时间，与`HAL_GetTick()`同一时间基准。同步获得新结果时可传`HAL_GetTick()`，不得给旧X/Y反复刷新时间。
- valid：X/Y和yaw都可信才为1。只有全局变量存在、IMU曾收到数据或车辆指令执行完毕，均不独立代表定位有效。
- 发布和读取均在主循环；若队友在中断计算定位，先将结果同步到主循环再发布，避免多字段同时读写。

默认无位姿；超过500ms未更新、坐标超出场地、非有限数或valid=0时读取失败。500ms为可调软件默认值，尚未用真实定位频率验收。

## 朝向对齐

源码中`control.c`定义my_yaw=0朝东，北为90度；`tf2d.c`的局部车头为+Y，因此默认`地图变换yaw = my_yaw - 90度`。地图变换角：北0度、东-90度、西90度、南-180度；输出统一为[-180,180)。

如果开机或归零时的真实车头与该约定不同，在静止且IMU稳定后调用：

```c
map_pose_yaw_offset_set(actual_map_heading_deg - my_yaw);
```

偏移改变会撤销旧快照，随后必须重新发布实际位姿。IMU归零和定位坐标重置前，先发布valid=0；完成对齐后再恢复有效。现有`hwt101.valid/last_update_ms`记录任意IMU有效帧，不能单独证明角度帧足够新。

## 建图端

定位接入后，主循环调用：

```c
map_obstacle_pose_task();
```

它读取统一位姿并转交`map_obstacle_task()`。位姿无效时仍服务雷达接收、清理道路待确认次数，保留已确认封路。需事先初始化道路地图（初始化方式以当前`map_update.h`为准），以及标定`tf_base`。本次没有切换现有`main.c`入口。

它沿用现有静止扫描规则，不在车辆运动期间生成新地图；软件空闲状态不独立证明实车停稳。下一阶段须在此基础上接入路径执行、实际到位判定、观测范围内道路放行、运动中障碍停车和重规划。未知道路未获观测确认前不能直接进入。
