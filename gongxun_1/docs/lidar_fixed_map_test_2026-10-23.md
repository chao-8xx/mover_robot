# 裸雷达固定测试位姿地图联调

当前仅连接开发板和雷达。测试使用人为指定的位姿，不代表IMU或里程计定位已经通过。

## 入口与规则

- `Core/Src/main.c`：`LIDAR_MAP_DESK_TEST_ENABLE=1`，`LIDAR_PILLAR_TEST_ENABLE=0`。
- 只初始化调试串口、雷达、坐标表和地图；不调用`system_init()`，不启动电机、里程计或导航执行任务。
- 固定位姿`(1200,2125,180°)`，零安装偏移。把雷达中心作为虚拟N1，原始0°指向N4。
- 原始整圈接收、完整聚类后再判断地图归属；裸雷达入口不使用车体屏蔽，正式`point_cloud_update()`仍使用原有屏蔽。
- 小柱规则沿用最近点220～1320mm、1～8点、横纵跨度各不超过100mm。
- 前方315°～45°候选用于显示；有效任务范围由正式地图计算：R8道路及前方N4节点，约`X=[1000,1400)、Y=[1000,1850)`。
- 不使用旧`map_lidar_test()`中400～600mm、左右200mm观察框。
- 跨圈确认沿用正式同位置观察：80mm关联半径、最近5圈命中至少3圈。节点内真实点沿用影响相连道路的现有规则。

## 操作

1. 固定雷达位置及朝向，扫描平面穿过柱身，人员及卷尺离开扫描平面。
2. 烧录复位，确认开机出现`LIDAR FIXED POSE MAP DESK TEST`，配置为`N1->N4 R8 wheel_mask=0`。
3. 移走小柱，短按KEY1。程序清空测试地图、清空待确认窗口，跳过两圈过渡数据后连续采集。
4. 看背景候选是否显示`task=0`，R8应保持UNKNOWN。若背景实际落入R8，也会如实确认，记录坐标核对。
5. 在原始0°方向、雷达读数约500mm处放小柱。正常应看到地图位置约`(1200,1625)`、`center=ROAD:8`、`task=1`，随后R8变为BLOCKED。
6. 移走小柱后`now`归零，已确认的BLOCKED保留。进行下一组独立摆放前短按KEY1清空地图重测。
7. 改变雷达位置或朝向后，只有同步修改固定测试位姿才能解释为同一地图；本轮保持雷达不动，仅移动目标。

## 摆放对照（角度和距离均以雷达读数为准）

| 原始方向及距离 | 预期地图位置约值 | 地图筛选 |
|---|---|---|
| 0°、500mm | (1200,1625) | R8，进入跨圈确认 |
| 30°、355mm | (1378,1818) | R8，验证偏角目标 |
| 335°、395mm | (1033,1767) | R8，验证另一侧目标 |
| 330°、674mm | (863,1541) | 禁入区，保留诊断但不进入道路确认 |
| 340°、1040mm | (844,1148) | R2，不属于当前R8任务，不确认 |
| 0°、925mm | (1200,1200) | N4，真实点影响R2/R3/R8/R9 |
| 0°、220mm | (1200,1905) | 当前N1，不属于前方任务选区 |

## 日志含义

- `[MAP FRAME] front`：正面第一层合格聚类数；`task`：本圈通过当前道路/前方节点筛选的候选数。
- `tracks`：窗口内候选位置数量；`confirmed`：窗口内已满足确认次数的位置数；历史位置不冒充当前回波。
- `[MAP CAND] map`：测距点组中心的地图坐标，不是圆柱拟合中心。
- `center=ROAD/NODE/FORBIDDEN/OUTSIDE:id`：中心点的静态区域，仅供诊断；OUTSIDE/FORBIDDEN的255表示无节点或道路编号。
- `pts_R/N/F/O`：该组真实点中，道路/节点/禁区/场外点数。真正道路归属由这些点决定，不填满包围框。
- `roads=0x...`：真实点涉及的道路位掩码，不等于已确认封路。
- `task=0/1`：该组是否有真实点进入当前R8及前方N4任务范围。
- `[MAP TRACK] hits`：同一位置最近5圈命中数；`now`表示本圈有无真实回波。
- `[MAP ROAD]`：长期道路状态；UNKNOWN不代表FREE，移柱不自动解封。
- `[MAP PATH] BLOCKED -> REPLAN`：旧路径受阻后只计算并打印候选绕行，不执行运动；未知道路仍打印SCAN。
- 接收中断或超时清空待确认窗口，已确认封锁保留；日志最多打印16个正面候选，超出会明确提示，处理仍使用全部候选。

## 切回其他入口

- 原始点与360格对照：`LIDAR_MAP_DESK_TEST_ENABLE=0`、`LIDAR_PILLAR_TEST_ENABLE=1`。
- 原有真实位姿观察：两个开关均为0。该入口仍需要IMU和四轮反馈，不能用于只有开发板与雷达的台架测试。
